## Note on the prediction this dispatch carried

The dispatch asserted that F1 could not exceed 48.0% recall "because F1 adds no
detection", and that a higher result would mean the measurement was wrong. The
run returned 50.0% with category-blind recall rising 48.0% → 53.1%. The premise
was wrong, not the measurement: deleting the section removed 22% of playbook
text, which changes detection as well as labelling. See the F1 result block in
`docs/protocols/recall-improvement-backlog.md`.
